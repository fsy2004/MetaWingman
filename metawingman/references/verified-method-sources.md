# Verified method sources

Use these as starting authorities and verify the current page/version again when a project begins.

| Authority | Scope | URL |
|---|---|---|
| Cochrane Handbook for Systematic Reviews of Interventions | intervention review planning, search, bias, synthesis, NMA, GRADE, interpretation | https://training.cochrane.org/handbook/current |
| PRISMA 2020 | core reporting | https://www.prisma-statement.org/home |
| PRISMA extensions | search, DTA, NMA, IPD, harms, scoping, living, COSMIN and other extensions | https://www.prisma-statement.org/extensions |
| JBI Manual for Evidence Synthesis | qualitative, effectiveness, textual, economic, etiology/risk, mixed methods, umbrella, scoping | https://synthesismanual.jbi.global |
| GRADE Working Group book | certainty of evidence and recommendations | https://book.gradepro.org |
| Cochrane risk-of-bias tools | RoB 2, ROBINS-I, ROBINS-E and related tools | https://www.riskofbias.info |
| QUADAS-3 | diagnostic accuracy risk of bias and applicability | https://www.bristol.ac.uk/population-health-sciences/projects/quadas/quadas-3/ |
| PROBAST+AI | prediction model quality, bias, and applicability | https://www.probast.org |
| EQUATOR Network | reporting-guideline discovery | https://www.equator-network.org/reporting-guidelines/ |
| NCBI E-utilities | PubMed/PMC API and usage policy | https://www.ncbi.nlm.nih.gov/books/NBK25497/ |
| PMC developer services | lawful automated PMC retrieval and licensing cautions | https://pmc.ncbi.nlm.nih.gov/tools/developers/ |
| Europe PMC REST API | publication metadata and OA full-text services | https://europepmc.org/RestfulWebService |
| Crossref REST API | DOI metadata and verification | https://www.crossref.org/documentation/retrieve-metadata/rest-api/ |
| Unpaywall API | open-access status and locations | https://data.unpaywall.org/products/api |
| ClinicalTrials.gov API v2 | trial registry retrieval | https://clinicaltrials.gov/data-api/api |

Do not copy proprietary or no-derivatives appraisal forms into the skill. Link to official versions and record the version used in each project.
