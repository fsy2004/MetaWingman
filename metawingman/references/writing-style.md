# Unified scientific writing and presentation style

## Argument

Build one continuous evidence-led story:

1. decision problem and why existing syntheses do not answer it;
2. prespecified question and methods chosen to answer it;
3. evidence identified and its limitations;
4. primary effects, heterogeneity, bias, robustness, and certainty;
5. what the evidence supports for the target decision;
6. what remains uncertain and how it should change future research or practice.

## Language

- Separate result, interpretation, and implication.
- Use causal verbs only when design and assumptions support a causal estimand.
- Match strength to certainty: `shows` or `supports` for strong evidence; `suggests` for bounded evidence; `is compatible with` for imprecise evidence; `does not establish` for unresolved questions.
- State uncertainty directly. Do not turn non-significance into equivalence or no effect.
- Avoid hype, priority claims without a verified landscape, generic importance statements, repeated conclusions, filler transitions, and defensive `not X but Y` framing.
- Use the same neutral tone for favorable, null, conflicting, and harmful outcomes.

## Consistency contract

Create a style sheet before drafting:

- canonical review title, short title, population, intervention/exposure/test, comparator, outcome names, timepoints, abbreviations, effect direction, reference group, and certainty terms;
- journal spelling and citation style;
- decimal precision by variable type and rules for leading zero, percentages, p values, CI/CrI, tau-squared and I-squared;
- table/figure numbering, legends, color palette, fonts, widths, and accessible contrast;
- manuscript headings mapped to PRISMA items and supplement locations.

Generate manuscript numbers from analysis outputs where possible. Use one rounding function and never manually transcribe a value already available in a machine-readable table.

## Figures and tables

- Forest plots show study estimates, uncertainty, weights when appropriate, pooled estimate, direction labels, and prediction interval where meaningful.
- Funnel plots are diagnostic displays, not proof of publication bias.
- NMA plots and league/rank outputs disclose sparse connections, inconsistency, and ranking uncertainty.
- RoB plots retain domain judgments; Summary of Findings tables carry explicit footnotes.
- Avoid rainbow palettes, 3D, truncated axes without justification, decorative charts, and tables that duplicate the text.
